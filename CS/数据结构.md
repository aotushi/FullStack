#### 1.1.2 解决问题方法的效率, 跟空间的利用效率有关

**案例说明**
> 使用循环和递归两种方式, 打印10万个正整数, 查看运行的时间.
> 递归的空间利用率远大于循环,导致占用过大,造成程序中断

```c
#include <stdio.h>
#include <time.h>

void PrintN(int N) {
	for (int i=0; i<N; i++) {
		printf("%d\n", i);
	}
	return;
}

void PrintN2(int N) {
	if (N > 1) {
		PrintN(N-1);
		printf("%d\n", N);
	}
	return;
}


int main() {
	int N;
	printf("请输入一个正整数: ");
	scanf("%d", &N);
	clock_t start = clock();
	PrintN2(N);
	clock_t end = clock();
	
	printf("Time: %.3f seconds\n", (double)(end - start) / CLOCKS_PER_SEC);

    return 0;
}
```

#### 1.1.4 什么是数据结构?
##### 1. **数据对象在计算机中的组织方式**

这包括两个层面:
- **逻辑结构**: 数据元素之间的逻辑关系(如线性、树形、图形等关系)
- **物理存储结构**: 数据在内存中的实际存储方式(如顺序存储、链式存储等)

##### 2. **数据对象必定与一系列加在其上的操作相关联**

数据结构不仅仅是数据的组织形式,还必须包括对这些数据的操作,比如:
- 插入、删除
- 查找、遍历
- 排序、修改 等等

##### 3. **完成这些操作所用的方法就是算法**
算法是实现这些操作的具体步骤和方法。

##### 更准确的理解

**数据结构 = 数据的组织方式 + 操作 + 算法**



#### 1.1.5 抽象数据集(Abstract Data Type)

**数据类型包含两个部分:**
1. **数据对象集** - 数据的值域
2. **数据集合相关联的操作集** - 可以对这些数据进行的操作

```
例1: 整数类型(int)
- **数据对象集**: 所有整数 {..., -2, -1, 0, 1, 2, ...}
- **操作集**: 加减乘除、比较大小等
```


**抽象**
意味着描述数据类型的方法不依赖于具体实现,具体体现在:
- ✅ **与存放数据的机器无关** - 不管是什么计算机硬件
- ✅ **与数据存储的物理结构无关** - 不管用数组还是链表实现
- ✅ **与实现操作的算法和编程语言均无关** - 不管用C++、Java还是Python实现

抽象数据类型只描述:
- **"是什么"** - 数据对象有哪些,支持哪些操作
- **不涉及"如何做到"** - 不关心底层如何实现

### 1.2 什么是算法

#### 1.2.1 概述

* 一个有限指令集
* 接受一些输入(有些情况下不需要输入)
* 产生输出
* 一定在有限步骤之后终止
* 每一条指令必须
	* 有充分明确的目标, 不可以有歧义
	* 计算机能处理的范围之内
	* 描述应不依赖于任何一种计算机语言及具体实现

如果不使用数据结构的话, 那么多项式相加就会写死,无法灵活操作.

错误做法:
```c

// 多项式1: 4x⁵ - 3x² + 1 
// 多项式2: 2x⁵ + x² + 5

int poly1() {
	return return 4*x**5 - 3*x**2 + 1
}

int poly2() {
	return 2*x**5 + x**2 + 5
}

// 如何相加?? 无法操作!
```

使用数组存储
```c
#include <stdio.h>

// 多项式1: 4x⁵ - 3x² + 1 
//poly1 = [1, 0, -3, 0, 0, 4] 下标就是指数

// 多项式2: 2x⁵ + x² + 5 
//poly2 = [5, 0, 1, 0, 0, 2]


void add_polynomial(int p1[], int p2[], int result[], int n) {
	for (int i=0; i<n; i++) {
		result[i] =  p1[i] + p2[i];
	}
}


int main() {
	// 多项式1: 4x⁵ - 3x² + 1 
	int poly1[] = {1, 0, -3, 0, 0, 4}; 
	// 多项式2: 2x⁵ + x² + 5 
	int poly2[] = {5, 0, 1, 0, 0, 2}; 
	int n = 6; // 数组长度 
	int result[6]; // 存储结果
	
	//相加
	add_polynomial(poly1, poly2, result, n)
	printf("相加结果: "); 
	print_polynomial(result, n); 
	// 结果应该是: 6x^5 + (-2)x^2 + 6 return 0;
}

```
