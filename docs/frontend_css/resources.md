# CSS 资料合集

这里收集 CSS 相关的长期资料入口，包括官方文档、专题网站、文章、工具、示例库、字体资源、书籍和后续可补充的视频、论坛资源。

## 官方文档与规范

- [MDN CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) - CSS 属性、模块、语法和浏览器兼容性的主要参考入口。
- [MDN Learn CSS: First steps](https://developer.mozilla.org/en-US/docs/Learn/CSS/First_steps) - 适合作为 CSS 入门路线的官方教程。
- [MDN Learn CSS: Building blocks](https://developer.mozilla.org/en-US/docs/Learn/CSS/Building_blocks) - 覆盖选择器、盒模型、值与单位、层叠等基础模块。
- [MDN CSS Selectors](https://developer.mozilla.org/zh-CN/docs/Web/CSS/CSS_Selectors) - 选择器语法、伪类和伪元素的参考入口。
- [W3C CSS Working Group](https://www.w3.org/Style/CSS/) - CSS 规范和工作组动态入口。

## 网站与文章

- [CSS-Tricks](https://css-tricks.com/) - CSS 技巧、布局、浏览器行为和实践文章。
- [The Shapes of CSS](https://css-tricks.com/the-shapes-of-css/) - 用 CSS 绘制形状的示例集合。
- [Inheriting `box-sizing` Probably Slightly Better Best Practice](https://css-tricks.com/inheriting-box-sizing-probably-slightly-better-best-practice/) - 关于 `box-sizing` 继承写法的说明。
- [大漠的 CSS 专栏](https://fedev.cn/css/) - 大漠在 fedev.cn 上整理的 CSS 文章集合。
- [现代 Web 布局](https://juejin.cn/book/7161370789680250917/section/7165496907714789407) - 大漠的布局与移动端适配相关内容。
- [如何在 Vue 项目中使用 vw 实现移动端适配](https://fedev.cn/mobile/vw-layout-in-vue.html) - Vue 项目中使用 vw 和 PostCSS 做移动端适配的参考。
- [Vue 使用 postcss-px-to-viewport 适配移动端、PC 端布局](https://www.goodsunlc.com/archives/507.html) - `postcss-px-to-viewport` 的项目配置参考。
- [关于移动端适配，你必须要知道的](https://juejin.cn/post/6844903845617729549#heading-21) - 移动端像素、视口和适配问题的整理。
- [PPI vs. DPI: what's the difference?](https://99designs.com/blog/tips/ppi-vs-dpi-whats-the-difference/) - 理解屏幕密度、图片和设计交付时可参考。
- [vw for layout](https://www.w3cplus.com/css/vw-for-layout.html) - 使用 vw 做布局适配的文章。
- [iPhone X 适配手Q H5 页面通用解决方案](https://aotu.io/notes/2017/11/27/iphonex/index.html) - 移动端安全区和异形屏适配参考。

## 书籍
