# 大屏看板

> [案例层] 数据大屏、监控面板要把固定比例设计稿铺满不同分辨率的屏幕。`rem` / `vw` / `scale` 的换算原理见[单位与等比还原](./units-and-scaling.md)，这一篇只讲大屏的选型和工程落地。

## 选型

| 方案              | 适用                     | 主要问题                       |
| ----------------- | ------------------------ | ------------------------------ |
| `rem + font-size` | 大屏中局部按比例换算     | 需维护根字号；两侧易留白       |
| `vw`              | 宽度驱动的等比页面       | 超宽屏高度不足 / 失衡          |
| `scale()`         | 固定设计稿比例的大屏看板 | 需处理缩放原点、留白、交互坐标 |

固定比例画布优先 `scale()`：容器按设计稿（如 `1920 * 1080`）原样开发，整体缩放一次，内部尺寸全部不动，最省心。`rem` / `vw` 也能做，但在超宽屏（如 `7680 * 2160`）下容易只显示一部分——原因和对比见[单位与等比还原](./units-and-scaling.md)。

## scale 落地

1. 定设计稿尺寸，容器按它写死（`width: 1920px; height: 1080px`）。
2. 用动态宽高比计算缩放比率（核心代码在[单位与等比还原](./units-and-scaling.md)）：屏幕更宽按高度缩放，不够宽按宽度缩放。
3. 多出来的区域留白（letterbox），优先保证画布完整显示。

### 工程细节

- **`transform-origin`**：默认 `50% 50%` 缩放后容易偏，通常设 `top left` 配合居中容器，缩放结果才可预测。
- **居中**：缩放后用定位 / `translate` 把画布居中，两侧或上下留白。
- **滚动**：大屏一般不滚动；若有滚动容器，注意 `scale` 会一并缩放滚动区域。
- **交互坐标**：`scale` 后元素的视觉位置和实际布局坐标不一致，拖拽、绘制、地图打点等要把鼠标坐标除以缩放比率还原。

`scale()` 不适合普通内容流页面（文字会一起被缩放，牺牲可读性），只用于固定版式的大屏。
