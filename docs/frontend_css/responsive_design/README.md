# Responsive Design

响应式设计要解决的，不是“PC 一套、移动端一套”，也不是“把 `px` 全换成 `rem` 或 `vw`”，而是：同一套页面在不同空间、输入、偏好下仍然可读、可用、可维护。

## 主题结构

按“知识屏蔽”三层递进组织（基础 / 通用 / 案例），上层只向下引用：

- **基础层（参考）**
  - [单位与等比还原](./units-and-scaling.md) —— `px`/`%`/`em`/`rem`/`vw`/`dvh`/`clamp` 等单位，及 `rem`/`vw`/`scale` 等比还原换算原理。
- **通用层（精华）**
  - [通用响应式方案](./general-responsive.md) —— 空间 / 输入 / 偏好三维度、布局优先、核心陷阱与配方。
- **案例层（应用）**
  - [桌面网站与后台](./case-desktop.md) —— 普通内容页 + 后台工具页。
  - 移动端适配 —— 分背景与案例两部分：
    - 背景：[像素与视口](./pixels-and-viewport.md) —— 物理像素 / CSS 像素 / DIP / DPR、三视口、`meta viewport`，移动端适配的前置概念。
    - 案例：[适配实战](./case-mobile-h5.md) —— 选型、`rem` 两流派与手淘、动态根字号最佳实践、纯 `vw` 活动页、Vue 工程接线、`1px` / 安全区 / 横屏 / 高清图。
  - [大屏看板](./case-dashboard.md) —— `scale()` 等比画布与超宽屏补位。

触摸事件、点击穿透、真机调试等内容不属于 CSS 响应式核心，已移至 `client_mobile`。
