# frontend_css

Scope: CSS language, layout, responsive design, animation, cascade, and maintainable styling.

Subtopics:

- [fundamentals](./fundamentals/) - syntax, values, units, how CSS is parsed and applied.
- [selectors_cascade](./selectors_cascade/) - selectors, specificity, inheritance, cascade layers, and scoping.
- [box_model_display](./box_model_display/) - box model, display types, inline/block/inline-block behavior.
- [layout](./layout/) - normal flow, Flexbox, Grid, positioning, writing modes, logical properties, and layout patterns.
- [responsive_design](./responsive_design/) - media queries, viewport, rem/vw/vh, mobile adaptation, large-screen adaptation.
- [typography_color](./typography_color/) - text, fonts, color, lists, links, and readable visual language.
- [visual_effects](./visual_effects/) - backgrounds, borders, shadows, gradients, filters, masks, and CSS shapes.
- [animation_transform](./animation_transform/) - transitions, animations, transforms, motion paths, and scroll-driven motion.
- [modern_css](./modern_css/) - container queries, nesting, custom properties, anchor positioning, view transitions, and new platform features.
- [architecture](./architecture/) - naming, layering, CSS modules, utility CSS, design tokens, maintainability.

Legacy content:

- `legacy/` keeps the original pre-classification container.
- Each subtopic has its own `legacy/` folder for moved old notes before rewriting.

Classification references:
