# JavaScript 资料合集

这里收集 JavaScript 相关的长期资料入口，包括官方文档、规范、教程、书籍、练习、代码片段和专题文章。

## 官方文档与规范

- [MDN JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) - JavaScript 指南、参考、内置对象、表达式、语句和函数入口。
- [MDN JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference) - 标准内置对象、语法、操作符和错误类型参考。
- [ECMAScript Language Specification](https://tc39.es/ecma262/) - ECMAScript 当前标准。
- [TC39](https://tc39.es/zh-Hans/) - JavaScript 标准委员会和提案入口。
- [TC39 Process](https://tc39.es/process-document/) - JavaScript 提案阶段说明。
- [TC39 Proposals](https://github.com/tc39/proposals) - JavaScript 新特性提案进度。
- [ECMA Standards](https://www.ecma-international.org/publications-and-standards/standards/) - ECMA 官方标准列表。
- [ECMAScript 6 Specification](https://262.ecma-international.org/6.0/) - 旧资料中经常引用的 ES6 规范版本。

## 教程与书籍

- [The Modern JavaScript Tutorial](https://javascript.info/) - 系统性的现代 JavaScript 教程。
- [web.dev Learn JavaScript](https://web.dev/learn/javascript) - Chrome 团队维护的 JavaScript 课程。
- [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) - MDN 的 JavaScript 学习指南。
- [You Don't Know JS Yet](https://github.com/getify/You-Dont-Know-JS) - Kyle Simpson 的 JavaScript 深入书系。
- [Exploring JS](https://exploringjs.com/) - Axel Rauschmayer 的 JavaScript 书籍和章节合集。
- [ECMAScript 6 入门](https://es6.ruanyifeng.com/) - 阮一峰的 ES6 中文教程。
