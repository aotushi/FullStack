# Vue

Vue 笔记不按官网 API 重新抄一遍，而是按一个项目从立项、开发、交付到维护的生命周期整理。

核心原则：

- 官网负责解释 API 是什么。
- 这里负责记录项目中如何组织、如何取舍、如何封装、如何维护。
- 基础概念只保留二次理解和容易踩坑的部分。

## 内容写法

每篇笔记优先回答三个问题：

1. 这个问题在项目中什么时候出现？
2. 常见做法为什么不够好？
3. 当前推荐方案是什么，以及它的边界是什么？
