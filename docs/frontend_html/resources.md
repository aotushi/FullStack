# HTML 资料合集

这里收集 HTML 相关的长期资料入口，包括官方文档、规范、教程、可访问性、SEO、字符实体和示例工具。

## 官方文档与规范

- [MDN HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) - HTML 参考、指南、元素、属性和表单资料入口。
- [MDN HTML Reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference) - HTML 元素、属性和相关参考文档。
- [HTML Living Standard](https://html.spec.whatwg.org/multipage/) - WHATWG 维护的 HTML 标准。
- [MDN HTML DOM API](https://developer.mozilla.org/en-US/docs/Web/API/HTML_DOM_API) - HTML 与 DOM API 的参考入口。
- [MDN Document Object Model](https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model) - DOM 基础概念和 API 入口。
- [MDN Introduction to the DOM](https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model/Introduction) - 旧 DOM 笔记中引用的 DOM 入门说明。
- [MDN Element API](https://developer.mozilla.org/en-US/docs/Web/API/Element) - 元素对象、属性和方法参考。

## 教程与课程

- [web.dev Learn HTML](https://web.dev/learn/html) - Chrome 团队维护的 HTML 系统课程，覆盖文档结构、语义、表单、媒体和可访问性。
- [MDN Structuring content with HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content) - MDN 的 HTML 内容结构学习模块。
- [MDN HTML forms](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms) - HTML 表单与表单交互教程。

## 可访问性与语义

- [WAI Tutorials](https://www.w3.org/WAI/tutorials/) - W3C WAI 的可访问性教程，覆盖页面结构、图片、表单、表格和组件。
- [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) - ARIA 组件模式、键盘交互和语义实践参考。
- [MDN Accessibility](https://developer.mozilla.org/en-US/docs/Web/Accessibility) - Web 可访问性概念、指南和参考入口。
- [Inclusive Components: Tooltips & Toggletips](https://inclusive-components.design/tooltips-toggletips/) - 旧 tooltip 笔记中引用的可访问提示组件文章。
- [Short note on aria-label, aria-labelledby, and aria-describedby](https://www.tpgi.com/short-note-on-aria-label-aria-labelledby-and-aria-describedby/) - 旧 ARIA 笔记中引用的命名与描述属性说明。
